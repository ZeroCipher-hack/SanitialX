# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in SanitialX, please report it privately rather than opening a public issue.

Include:
- A clear description of the issue
- Steps to reproduce
- Affected component or endpoint
- Potential impact
- Any relevant logs or proof of concept

Please do not include real credentials, secrets, personal data, or production data in reports.

## Scope

Security reports should focus on vulnerabilities in the SanitialX codebase and its security-sensitive configuration.
